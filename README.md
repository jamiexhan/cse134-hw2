<h1>Validator Error Reasoning</h1>
Using the validator, I realized each of my Netlify pages presented errors and did not validate, specifically in lines that are not present in my code. For example, index.html has a stray start tags script error in line 66 but my index.html code only goes up to line 59. When I view page source, I realize that Netlify has added its own code to the end: </html><script async src="/.netlify/scripts/hud?variant=public" data-nf-variant="public" data-netlify-site-id="dc7c5e7f-985b-46d2-bd40-654b4994a819" data-app-host="app.netlify.com"></script>. To ensure that my own code was working, I validated my files locally instead of through Netlify. No errors were shown so we can confirm that Netlify is the problem. Therefore, I attempted to disable the Heads-up Display and Netlify Drawers, as well as checked if there were any snippet injections, and redeployed. The same error pops up, so I believe Netlify injects this script at serve time, so the validator sees it as content after the closing tag.
